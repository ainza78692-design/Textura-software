# Textura ERP - WiX MSI Installer

This directory contains the modern WiX Toolset v4/v5 source code for packaging Textura ERP as a standard Windows Installer (`.msi`).

## Requirements
- [.NET SDK](https://dotnet.microsoft.com/download) (Required to install the modern WiX tool)
- WiX Toolset installed globally via dotnet: `dotnet tool install --global wix`

## Building the MSI

1. **Prepare the Application Files:**
   First, ensure the raw Electron application files are generated by `electron-builder`. From the root of the project, run:
   ```bash
   npm run desktop:build
   ```
   *(This populates the `release/electron/win-unpacked` folder).*

2. **Generate the MSI:**
   Double-click `build.bat` or run `build.ps1` from PowerShell.
   
   The script will:
   - Automatically read the correct version from `package.json`.
   - Ensure the WiX tool is installed.
   - Compile `Package.wxs` and dynamically harvest all files from `win-unpacked`.
   - Output `Textura-ERP-Setup-1.0.18.msi` (or whatever the current version is).

## Code Signing
To sign the installer, run signtool against the generated `.msi` file:
```cmd
signtool.exe sign /a /fd SHA256 /tr http://timestamp.digicert.com Textura-ERP-Setup-1.0.18.msi
```
