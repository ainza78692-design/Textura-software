## 1. PostgreSQL

Create the database and user on the server.

```sql
create database textile_invoice;
create user invoice_app with encrypted password 'strong_password';
grant all privileges on database textile_invoice to invoice_app;
```

Run migrations from the project root:

```bash
psql "postgresql://invoice_app:strong_password@localhost:5432/textile_invoice" -f database/migrations/001_init_schema.sql
```

## 2. Backend Server

```bash
cd backend
npm install
cp .env.example .env
npm run build
npm start
```

The backend exposes:

```text
GET /health
POST /api/auth/login
POST /api/auth/bootstrap-admin
POST /api/auth/register
GET /api/auth/me
GET /api/invoices
POST /api/invoices
GET /api/invoices/:id
PATCH /api/invoices/:id
PATCH /api/invoices/:id/documents/:documentCode
POST /api/invoices/:id/final-submit
```

## 3. Client PCs / Electron Desktop App

Configure the frontend or packaged desktop app with:

```env
VITE_API_BASE_URL=http://SERVER_IP:4000/api
```

Client PCs should never connect directly to PostgreSQL.

Build the desktop installer on a Windows machine with Node.js installed:

```powershell
npm install
npm run desktop:icon
npm run desktop:build
```

The installer is generated by Electron Builder under:

```text
release/electron/
```

The Electron app loads the Vite desktop renderer from `dist/desktop-renderer` and persists token, server URL, and theme settings through browser storage inside the desktop shell.

## 4. First Admin

After migrations and backend startup, open the app and use the setup admin tab once. After the first user exists, bootstrap closes automatically. For production, set this after setup:

```env
BOOTSTRAP_ADMIN_ENABLED=false
```

If users already exist and you need to create or reset an admin account, run this on the backend server:

```powershell
cd backend
npm run admin:reset -- --email=admin@example.com --password=StrongPass123 --name="System Administrator"
```
